# Hasil validasi ulang kelas 10

Model LLM: `gemini-3.1-flash-lite`; metode blind N=3, rubrik kelas sasaran, verifikasi kunci/solusi, dan adjudikasi AI bila diperlukan. Label terkunci sebelum diagnostik IndoBERT.

Gunakan [validation_results.json](validation_results.json) untuk data hasil dan `cognitive_level`, `cognitive_score`, `confidence_score` dan `status` pada setiap dokumen soal. Baca [LAPORAN_VALIDASI.md](LAPORAN_VALIDASI.md) untuk soal, perhitungan confidence/entropy, tiga suara, profil difficulty, adjudikasi, serta hasil akhir per soal. [questions.json](questions.json) memuat sumber dan spesifikasi jawaban terbatas; [indobert_predictions.json](indobert_predictions.json) memuat diagnostik artifact yang dipilih.

Distribusi: `{"mathCognitiveDomain": {"applying": 38, "knowing": 7, "reasoning": 1}, "knowledgeDimension": {"conceptual": 18, "procedural": 27, "factual": 1, "metacognitive": 0}, "intendedDifficulty": {"Easy": 33, "Medium": 13, "Hard": 0}}`. Routing: `{"silver_ready": 46}`.

Token sukses tercatat: 543,494; tidak ada API call pada packaging. Provider dapat mencatat lebih banyak usage dari percobaan yang tidak menghasilkan output valid. Label tetap silver AI; CTT/IRT belum dihitung. Artifact diagnostik `indobert-3x4x3-silver-kelas1-v1` memakai dataset `kelas1-gemini-silver-n3-v1`. Packaging ini tidak melatih atau mempromosikan model; diagnostik tidak menentukan label blind.

Audit tidak menyetujui ekspansi/training bila gate belum lolos. Gate batch: `{"allExpectedItemsPresent": true, "threeSuccessfulRunsAtLeast90Percent": true, "insufficientOrAbstainedBelow10Percent": true, "blindPromptLeakageAbsent": true, "checkpointSourceAndInputsMatch": true, "promptAndRubricVersionMatch": true, "requiredEvidenceComplete": true, "boundaryAnalysisClear": false}`.

Kelas 10 memakai rubrik SMA. Artifact diagnostik berada di luar cakupan kelas/jalur ini: semua head abstain dengan label/confidence/entropy null dan probabilitas kosong. Tidak ada prediksi atau perbandingan ketepatan IndoBERT untuk kelas/jalur ini; label akhir mengikuti penilaian blind Gemini.

Kelompok difficulty tersedia di [difficulty_groups.json](difficulty_groups.json), [Easy](difficulty/Easy.json), [Medium](difficulty/Medium.json), dan [Hard](difficulty/Hard.json). `contentQualified` hanya menandai soal tanpa blocker konten; soal silver_ready dapat masuk snapshot operasional. Kategori kosong tetap diekspor. Item tanpa keputusan tersedia di [undecided](difficulty/undecided.json).

Format `validation_results.json`: array dokumen dengan field yang sama seperti `soal_pretest_db.json`, tanpa envelope atau `ai_metadata`. `cognitive_level` memakai difficulty final AI (easy/medium/hard, huruf kecil). Domain knowing/applying/reasoning tetap disimpan sebagai `manifest.json.databaseExport.metadataByQuestionId[<_id>].math_cognitive_domain` dan dalam audit. `cognitive_score`: easy=600, medium=1000, hard=1400, sebagai skor awal kesulitan, bukan kemampuan siswa atau parameter IRT. `confidence_score = round(100 × min(dukungan label final tiap head / requestedRuns))`: 100 untuk 3/3, 67 untuk 2/3, 33 untuk 1/3. Dukungan dihitung ulang dari run awal, bukan `supportingVotes` yang dapat merujuk label mayoritas sebelum adjudikasi. Skor ini mengukur konsistensi AI, bukan probabilitas akurasi; adjudikasi tidak menambah suara. `status` hanya active/inactive: silver_ready menjadi active; revision_required/needs_ai_review menjadi inactive. Hanya active boleh dipakai untuk delivery. Routing final asli tetap tersimpan di metadata `validation_status` dan audit, sehingga alasan item inactive tetap dapat diperiksa. Bukti keputusan lengkap tersedia di [decision_audit.json](bukti_validasi/decision_audit.json). `manifest.json.databaseExport` menyimpan summary, rumus, provenance, track dan metadata per `_id`, termasuk ID versi/hash snapshot operasional. ID versi/hash item yang ditahan tetap null. `kelas_id`, `berkas_id` dan pemetaan `subbab_id` tetap mengikuti sumber dan diselesaikan seeder backend. Path gambar tetap relatif terhadap folder kelas sumber; JSON ini memuat kunci jawaban dan hanya untuk backend.
