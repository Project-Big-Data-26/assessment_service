# Kategori operasional relatif

Array validation_results.json membagi soal aktif berdasarkan profil bukti menjadi tiga kelompok mendekati sama banyak.
Hard berarti kelompok dengan ranking tertinggi dalam bank kelas ini; label ini relatif dan tidak menyatakan Gemini menilai seluruh soal itu Hard.
balance_audit.json mencatat skor heuristik, kuota, dukungan run AI dan batas kategori yang memotong skor sama.
confidence_score memakai dukungan run AI asli terhadap label operasional, sehingga dapat 0.
ai_validation_results.json dan ai_decisions.json mempertahankan label serta bukti keputusan AI asli.
Versi ini tidak mengubah bundle AI, status aktif, isi soal, data training atau kalibrasi IRT.
