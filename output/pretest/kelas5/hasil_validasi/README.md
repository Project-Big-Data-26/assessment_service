# Validasi AI silver — kelas5

72 soal, 216 run blind sukses. Routing: `{'silver_ready': 70, 'revision_required': 2}`. Label: `{'Easy': 48, 'Hard': 2, 'Medium': 22}`.

Gunakan [validation_results.json](validation_results.json) untuk keputusan silver, [LAPORAN_VALIDASI.md](LAPORAN_VALIDASI.md) untuk bukti, dan [difficulty_groups.json](difficulty_groups.json) untuk kelompok kesulitan.

Alur operasional memakai AI silver tanpa persetujuan pelabel manusia. Hanya `silver_ready` masuk snapshot delivery; `revision_required` dan `needs_ai_review` ditahan untuk AI revalidation. Jalankan `scripts/build_operational_silver.py` untuk snapshot yang memverifikasi checkpoint, kunci, solusi dan aset. IRT menyimpan difficulty empiris terpisah. Gate training, evaluasi dan mutu estimasi tetap berlaku. Prompt, rubrik, jawaban dan label blind terdahulu tetap terkunci.

Format `validation_results.json`: array dokumen dengan field yang sama seperti `soal_pretest_db.json`, tanpa envelope atau `ai_metadata`. `cognitive_level` memakai label final AI (knowing/applying/reasoning). `cognitive_score`: Easy=600, Medium=1000, Hard=1400, sebagai skor awal kesulitan, bukan kemampuan siswa atau parameter IRT. `confidence_score = round(100 × min(dukungan label final tiap head / requestedRuns))`: 100 untuk 3/3, 67 untuk 2/3, 33 untuk 1/3. Dukungan dihitung ulang dari run awal, bukan `supportingVotes` yang dapat merujuk label mayoritas sebelum adjudikasi. Skor ini mengukur konsistensi AI, bukan probabilitas akurasi; adjudikasi tidak menambah suara. `status` mempertahankan routing final; hanya `silver_ready` boleh dipakai untuk delivery. Soal `revision_required`/`needs_ai_review` tetap ditahan meskipun skor terisi. Bukti keputusan lengkap tersedia di [decision_audit.json](bukti_validasi/decision_audit.json). `manifest.json.databaseExport` menyimpan summary, rumus, provenance, track dan metadata per `_id`, termasuk ID versi/hash snapshot operasional. ID versi/hash item yang ditahan tetap null. `kelas_id`, `berkas_id` dan pemetaan `subbab_id` tetap mengikuti sumber dan diselesaikan seeder backend. Path gambar tetap relatif terhadap folder kelas sumber; JSON ini memuat kunci jawaban dan hanya untuk backend.
