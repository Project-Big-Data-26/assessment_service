*orisinal | C5 | 4 langkah | jenis: evaluasi klaim diagonal tegak lurus*

Untuk vektor tak nol $\mathbf{u}$ dan $\mathbf{v}$ pada bidang, vektor $\mathbf{u} + \mathbf{v}$ ortogonal terhadap $\mathbf{u} - \mathbf{v}$ jika dan hanya jika ....

- **A. $\|\mathbf{u}\| = \|\mathbf{v}\|$** ✅  
  <sub>Benar: (u+v).(u-v) = u.u - u.v + v.u - v.v = |u|^2 - |v|^2</sub>
- B. $\mathbf{u}$ dan $\mathbf{v}$ sejajar  
  <sub>Salah: u=<1,0>, v=<0,1> tidak sejajar tetapi (u+v).(u-v) = 0</sub>
- C. $\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|^2$  
  <sub>Salah: tidak ekuivalen; u=<2,0>, v=<2,2> memenuhi u.v = |u|^2 = 4 tetapi (u+v).(u-v) = -4</sub>
- D. $\mathbf{u}$ ortogonal terhadap $\mathbf{v}$  
  <sub>Salah: u=<1,0>, v=<0,2> ortogonal tetapi (u+v).(u-v) = -3, bukan 0</sub>

**Pembahasan:** $(u+v)\cdot(u-v)=u\cdot u-v\cdot v=\|u\|^2-\|v\|^2$ (sifat komutatif dan distributif), nol tepat bila $\|u\|=\|v\|$.
**Acuan:** siswa — siswa hal.194

### 54. [hard] kelas11_tl-b04-b-hard-bt01-014
*orisinal | C5 | 5 langkah | jenis: syarat parameter sudut tumpul pada segitiga*

Pada bidang koordinat terdapat titik $A(0, 0)$, $B(4, 0)$, dan $C(x, 1)$ dengan $x$ bilangan bulat. Banyak nilai $x$ yang membuat sudut $ACB$ tumpul adalah ....

- **A. 3** ✅  
  <sub>Benar: CA = <-x,-1>, CB = <4-x,-1>; CA.CB = x^2 - 4x + 1 < 0 untuk 2 - akar3 < x < 2 + akar3 (kira-kira 0,27 < x < 3,73), bilangan bulat 1, 2, 3</sub>
- B. 2  
  <sub>Salah: mengira batas pembuatnya x = 1 dan x = 3 tidak termasuk, atau menghitung hanya x = 1 dan 3</sub>
- C. 5  
  <sub>Salah: memakai batas 0 <= x <= 4 (seolah titik C pada diameter y = 0) sehingga mendapat 0,1,2,3,4</sub>
- D. 4  
  <sub>Salah: mengira interval 0 <= x <= 4 dikurangi satu titik; akar sebenarnya 2 -/+ akar3, bukan 0 dan 4</sub>

**Pembahasan:** $\overrightarrow{CA}\cdot\overrightarrow{CB}=(-x)(4-x)+(-1)(-1)=x^2-4x+1<0$ untuk $2-\sqrt3<x<2+\sqrt3\approx(0{,}27;\,3{,}73)$. Bilangan bulatnya 1, 2, 3.
**Acuan:** siswa — siswa hal.198

### 55. [hard] kelas11_tl-b04-b-hard-bt01-015
*orisinal | C5 | 5 langkah | jenis: merancang vektor dengan sudut yang sama*

Diketahui $\mathbf{u} = \langle 1, 0\rangle$ dan $\mathbf{v} = \langle 3, 4\rangle$. Vektor $\mathbf{w} = \langle 1, k\rangle$ dengan $k > 0$ membentuk sudut yang sama besar dengan $\mathbf{u}$ dan dengan $\mathbf{v}$. Nilai $k$ adalah ....

- A. $\frac{4}{3}$  
  <sub>Salah: mengambil kemiringan v sebagai kemiringan w; itu membuat w searah v, bukan sudut sama</sub>
- B. $1$  
  <sub>Salah: mengira w = <1,1> sebagai garis bagi tanpa memperhitungkan |v| = 5</sub>
- **C. $\frac{1}{2}$** ✅  
  <sub>Benar: cos(w,u) = 1/|w| dan cos(w,v) = (3+4k)/(5|w|); sama bila 3 + 4k = 5, k = 1/2</sub>
- D. $\frac{3}{2}$  
  <sub>Salah: menyamakan 3 + 4k dengan 5 lalu keliru menyelesaikan (4k = 6)</sub>

**Pembahasan:** $\cos\angle(w,u)=\frac{1}{\|w\|}$ dan $\cos\angle(w,v)=\frac{3+4k}{5\|w\|}$. Sama bila $3+4k=5$, jadi $k=\frac12$.
**Acuan:** siswa — siswa hal.197
